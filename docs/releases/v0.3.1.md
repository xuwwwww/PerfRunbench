# PerfRunbench v0.3.1 Release Notes

PerfRunbench v0.3.1 is a user experience and portability validation update.

This release focuses on improving the public release workflow and validation
for generic command tuning and platform readiness. It does not introduce any new
performance claims beyond the existing v0.3.0 evidence.

Key points:

- UX improvements for config-free tuning with `autotuneai run --auto`.
- New `quick`, `standard`, and `deep` presets for predictable tuning budgets.
- Hard wall-time budget enforcement and partial report generation when tuning
  is interrupted by a deadline.
- Added `autotuneai platform validate` to verify environment readiness and
  portability constraints before tuning or production use.
- Kernel and system tuning are now advanced opt-in features instead of being
  applied by default.
- Fixed the wall-time canary process-scope tuning path to improve cleanup and
  validation reliability.

Compatibility and evidence:

- v0.3.1 does not change the validated C7g/T4g serving evidence published in
  v0.3.0.
- The existing v0.3.0 performance evidence remains unchanged.
- PerfRunbench v0.3.1 is published as a GitHub Release. It has not been
  published to PyPI.
